# 今日のニュース

速報／主要・国内／国際／IT・テクノロジー／ゲーム／災害のニュース見出しを自動で集めて表示するサイトです。

- 公開URL: https://ataisaikyou.github.io/daily-news/
- Cloudflare Worker（[worker/](worker/)）が **5分の倍数の時刻**（0分・5分・10分…）に GitHub Actions を起動し、GitHub Pages に公開します
  - **速報**・地震情報：5分の倍数の時刻ごとに取得（「今すぐ更新」から4分以内のときは見送り）
  - その他のニュース：**毎時0分・30分** に取得
  - 「今すぐ更新」ボタン：その場で全ニュースを取り直す
  - GitHub の定期実行（30分ごと）は予備。Worker からの更新が15分以上ないときだけ動きます
- **並び替え**：中央のジャンル別一覧は「新しい順」と「人気順」を切り替えられます
  - 人気順：24時間以内の記事を、はてなブックマーク数と同じ話題を報じた媒体の数で点数化して並べます（5分ごとに数え直し）
- **今日・昨日**：NHK・Yahoo!ニュースの「主要」に載ったニュースを日付ごとに蓄積して一覧表示
- **X**：各ジャンルの「Xで検索」リンク（X上の最新投稿を開くだけで、データは取り込まない）
- 地震情報はページを開いている間、ブラウザが **2分ごと** に最新を取得します（P2P地震情報 API）

前回の取得結果は公開サイトの `state.json` に保存し、次の実行で読み戻して引き継ぎます。

## ニュースの取得元・更新間隔を変える

[feeds.mjs](feeds.mjs) を編集して push するだけです（push すると自動で再公開されます）。

## 今すぐ更新したいとき

サイト上部の **今すぐ更新** ボタンを押します（全ニュースを取り直します）。
GitHub のリポジトリ → **Actions** → **ニュース更新** → **Run workflow** でも同じことができます。

## 手元で確認する

```
npm install
npm run build     # dist/ にサイトを生成
npm run preview   # http://localhost:8080 で表示
```
